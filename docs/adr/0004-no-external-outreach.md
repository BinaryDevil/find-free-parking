# Use available evidence without external outreach

Accepted 2026-10-14 by the project owner. Source discovery uses evidence we can find through existing public documents, datasets, services and read-only queries. No request will be sent to officials, governments or service providers: no email, contact form, public-records request, permission inquiry, support ticket or other outreach, whether by a human, agent or automation acting for this project.

This supersedes ADR-0002’s data-request fallback and all earlier outreach plans or drafts. Do not prepare or file new outreach tasks, send existing drafts, or ask the owner to authorize them. Ordinary read-only retrieval of existing public information remains allowed.

Missing evidence stays missing. Public accessibility is not reuse permission. Sources still must satisfy every [Evidence Source Policy](0002-evidence-source-policy.md) criterion; unresolved rights, schedules, precision, currentness or safety contradictions leave them pending or excluded. Affected parking stays Unknown, and Coverage must state the narrower supported subset or none. Internal source review remains required and cannot manufacture third-party permission. Broader coverage may be unavailable under this decision; change it only through an explicit superseding owner decision.
