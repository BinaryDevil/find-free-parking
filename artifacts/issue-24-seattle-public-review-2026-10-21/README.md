# Seattle reviewer evidence, 2026-10-21

Read with [the assessment](../../docs/sources/seattle-public-review-2026-10-21.md). This packet supports a pending/excluded verdict; it approves no source.

- `<service>-<layer>.json`: official layer URL, fresh count, complete field metadata, geometry type, edit timestamps, exact service item ownership/access/terms and ten safe projected records (two/one for genuinely smaller layers). `retrieved_utc` records the actual retrieval time. Queries: layer `?f=json`; `/query?f=json&where=1%3D1&returnCountOnly=true`; `/query` with explicit saved sample fields, `returnGeometry=false`, `resultRecordCount=10`; service metadata supplies `serviceItemId`, then official ArcGIS sharing REST item metadata supplies public access/terms.
- `*-comparisons.json`: saved ten distinct curb keys; source rows selected from at most 2,000 projected records, joined by `ELMNTKEY in (<saved keys>)` to Blockface and Parking Features 4 using the explicit field projections visible in the responses. The selected first ten are research starts, not a claim of ten representative safety passes. All returned sign rows are retained. A duplicate view is not independent field observation.
- `representative-safety-cases.json`: deliberate permit, metered, time-limited, no-parking, loading and transit cases. The public keys and compared fields are in the file. This supplements the first-ten selection; it does not complete exact curb extents or C7.
- `rpz-targeted-zones.json`: all 35 zone polygon summaries and structured/full-text sign queries for the ten curb keys in the assessment. Different layer views of a sign are identified; the zone polygon is a distinct official regulation summary.
- `unpaid-schedules.json`, `lot-rule-fields.json`, `tier-rates.json`: fresh explicit safe projections. No private contact, applicant, owner, phone or individual payment/request event values were requested. Public tow-service telephone text may appear as part of official static signs. Public road/lot addresses and official static sign texts are rule context, not driver locations.
- `signal-*.json`: public catalog field metadata, edit timestamp, licence ID and aggregate-only `count(*)`; no individual transactions, occupancy events, service requests or citations were retrieved.
- `reference-retrievals.json`: public HTML references freshly read with the web reader, plus the failed direct Diamond JSON fetch (HTTP 403; no bypass) and the unverified dynamic code extraction. Exact HTML text snapshots are not included; review links remain the primary source for those summaries.
- `SHA256SUMS.json`: SHA-256 hashes of every JSON response artifact except the checksum manifest itself.

Counts are retrieval observations, not imported records, unique permitted places, active rules, completeness claims, freshness of field inspections, or Coverage. Samples deliberately retain ambiguity; no fixture is approved for production import. Source response geometry was not stored, and exact spatial safety was not verified. No auth credentials or database operations were used.
